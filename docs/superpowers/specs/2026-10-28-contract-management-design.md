# 合同管理模块设计

## 目标

在客户画像系统中新增独立合同管理模块，提供合同列表查询、新增、查看、编辑、删除、Excel 导入、Excel 导出和本地持久化能力。业务字段以用户提供的 `合同额.xlsx` 为准，附件当前仅包含表头，没有示例数据。

## 字段定义

面向用户展示和 Excel 导入导出的 9 个字段：

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 部门合同号 | 文本 | 必填、去空格后按大写比较，完整合同数据内唯一 |
| 合同名称 | 文本 | 必填 |
| 客户单位名称 | 文本 | 必填 |
| 主办部门 | 文本 | 必填 |
| 业务类型 | 文本 | 必填 |
| 单个合同金额 | 数值 | 必填，大于 0，单位万元 |
| 客户单位联系人 | 文本 | 选填 |
| 客户单位联系电话 | 文本 | 选填，保存为文本并保留前导零 |
| 提交时间 | 日期 | 必填，统一保存为 `YYYY-MM-DD` |

内部附加字段仅用于系统管理，不导出到 Excel：

- `id`：稳定记录 ID
- `createdAt`：创建时间
- `updatedAt`：更新时间
- `source`：`seed`、`manual` 或 `import`

## 页面结构

新增侧边栏菜单“合同管理”，位于“企业管理”和“企业搜索”之间。

页面包含：

1. 顶部概览：合同总数、当前筛选结果数、合同总金额、涉及客户数。
2. 工具栏：关键词搜索、主办部门筛选、业务类型筛选、金额区间、提交日期范围、新增合同、导入 Excel、导出 Excel。
3. 合同表格：显示 9 个业务字段、操作列，支持按金额和提交时间排序。
4. 分页：每页 10、20 或 50 条，默认 20 条。
5. 行操作：查看、编辑、删除。
6. 空状态和无匹配结果状态。

## 新增与编辑

- 使用统一表单弹窗。
- 必填项为空、金额无效、日期无效或合同号重复时阻止提交，并在对应字段旁显示错误。
- 新增后自动生成 ID 和创建、更新时间。
- 编辑时保留原 ID 和创建时间，更新 `updatedAt`。
- 表单关闭后保留已验证数据改动，不执行半写入。

## 查看与删除

- “查看”打开只读详情弹窗，完整展示 9 个字段。
- “删除”必须经过二次确认。
- 删除后立即从列表与持久化数据中移除。

## 查询与筛选

- 关键词同时匹配合同号、合同名称、客户名称、主办部门、业务类型和联系人。
- 主办部门和业务类型为动态选项，由当前合同数据生成。
- 金额区间支持：全部、100 万以下、100–500 万、500–1000 万、1000 万以上。
- 提交日期支持起止日期筛选。
- 筛选、排序和分页在客户端即时完成。
- 顶部总金额和客户数使用当前筛选结果计算。

## Excel 导入

- 使用浏览器端 Excel 库支持标准 `.xlsx`，不解析旧式 `.xls` 或 CSV。
- 优先读取第一个工作表，并按附件中的 9 个中文表头映射字段；允许表头两侧空白。
- 导入流程分为“选择文件 → 解析预览 → 确认导入 → 显示结果”。
- 预览显示：可导入数、重复数、错误数、总行数。
- 每行展示状态和错误原因；错误行不得导入。
- 重复判定使用规范化后的部门合同号。
- 默认跳过重复合同；提供“覆盖重复合同”选项，勾选后以导入行更新现有记录。
- 日期单元格转换为 `YYYY-MM-DD`，金额自动移除千分位和人民币符号，电话保持文本。
- 缺少必需表头时停止导入并提示具体缺失字段。

## Excel 导出

- 提供“导出筛选结果”和“导出全部”两个入口。
- 导出列顺序与附件完全一致，表头名完全一致。
- 文件名包含模块名和日期，例如 `合同管理_2026-10-28.xlsx`。
- 提供“下载导入模板”，导出仅含 9 个表头的空工作簿。

## 数据来源与持久化

- 首次使用时从 `COMP_MOCK_LIST` 的现有合作合同生成演示数据，使页面开箱可用。
- 后续所有新增、编辑、删除和导入结果通过 `usePersistentState` 持久化到 `saibao.contracts`，版本为 1。
- 本模块是唯一消费者，不新增全局 Context。
- 持久化校验失败时回退演示数据，不让损坏数据导致页面崩溃。

## 文件边界

- `src/types/contract.ts`：合同记录、草稿、导入行和筛选类型。
- `src/data/contractData.ts`：字段定义、演示数据、校验、规范化、筛选辅助函数。
- `src/data/contractExcel.ts`：Excel 解析、预览、导出和工作簿构建。
- `src/components/contracts/ContractManagementModule.tsx`：页面容器和 CRUD 状态。
- `src/components/contracts/ContractFormModal.tsx`：新增、编辑和详情弹窗。
- `src/components/contracts/ContractImportModal.tsx`：导入预览与确认。
- `src/App.tsx`：新增路由和侧边栏入口。
- `package.json`：增加 `read-excel-file` 与 `write-excel-file` 浏览器端 Excel 依赖。

## 错误处理

- 文件解析失败、无工作表和表头缺失时禁止提交，并显示可操作的中文错误。
- 导入过程中只有“确认导入”后才修改主数据。
- 本地存储写入失败时，当前会话继续可用，数据保持内存状态。
- 删除、覆盖导入等不可逆操作必须有明确确认。

## 验收标准

- 侧边栏可见“合同管理”，页面能正常加载演示合同。
- 新增、查看、编辑、删除均能更新列表和本地存储，刷新后数据保留。
- 关键词、部门、业务类型、金额和日期组合筛选结果正确。
- 导入附件格式能够成功预览，重复项默认跳过，错误行被拒绝。
- 覆盖模式能够更新重复部门合同号对应记录。
- 导出文件包含准确 9 列，金额、日期和电话类型合理。
- 模板导出包含附件相同表头。
- 生产构建成功，本次新增文件不引入 TypeScript 错误。
- 在桌面和窄屏下，工具栏、表格和弹窗可操作且无关键内容被遮挡。

## 来源

业务字段来自用户提供的 `合同额.xlsx`，该文件仅包含 9 个表头，没有数据行。

## 问答交互补充

合同管理以 AI 问答为主要使用入口，表格页面同时作为查询结果核验和后台维护界面。

- 新增共享 `ContractProvider`，合同管理页面与 AI 助手读取同一份实时合同数据。
- AI 助手支持最近合同、指定企业合同、指定部门合同、指定业务类型合同、合同编号查询，以及按部门或业务类型汇总合同金额。
- 合同问答返回结构化结果卡片，包含甲方、部门、金额、合同号和提交时间，并提供“打开合同管理”按钮。
- 合同管理页面提供“问 AI 查合同”入口；企业画像的合同区域提供“合同管理”入口。
- 问答结果使用内置合同数据现场计算，并沿用现有模拟数据来源提示。
