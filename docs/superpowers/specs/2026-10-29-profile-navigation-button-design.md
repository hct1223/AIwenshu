# 完整画像导航按钮设计

## 目标

让 AI 企业画像卡和集团画像卡中的“查看完整画像”成为明确、可聚焦的按钮，并在点击后跳转到对应完整画像页面。

## 当前问题

- “点击查看完整画像 →”目前只是卡片内普通文字，不是按钮，键盘用户无法聚焦。
- 整张卡片虽然绑定了点击事件，但交互提示不明确。
- 跳转后 AI 侧栏仍然打开并占用页面宽度，画像内容被压缩。

## 实现方式

- 新增可复用的 `ProfileLink` 按钮组件。
- 企业画像卡使用企业 ID 调用现有 `onNavigateToCompany`。
- 集团画像卡使用集团 ID 调用现有 `onNavigateToGroup`。
- 点击按钮时阻止事件冒泡，避免触发卡片自身的其他点击行为。
- 跳转成功后收起 AI 侧栏。
- 保留整卡点击能力，并让整卡点击执行相同的跳转和收起逻辑。

## 行为

- 按钮文案为“查看完整画像”，带右箭头。
- 按钮提供明确的 hover、focus-visible 和键盘 Enter/Space 支持。
- 企业画像跳转到 `enterprisePortrait` 对应企业。
- 集团画像跳转到 `groupPortrait` 对应集团。
- 跳转后 AI 侧栏关闭，页面恢复完整宽度。

## 验收标准

- 企业画像卡中的“查看完整画像”以 button 角色出现。
- 点击企业按钮后显示所选企业完整画像。
- 点击集团按钮后显示所选集团完整画像。
- 跳转完成后 AI 侧栏关闭。
- 原有卡片展开/收起按钮和合同查询流程不受影响。
- 相关测试通过，生产构建成功。
