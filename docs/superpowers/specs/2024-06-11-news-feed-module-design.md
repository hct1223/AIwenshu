## 项目概述

为云上赛宝数智专盘系统添加行情速递模块，提供行业最新政策、市场趋势、投标信息、每日最新热点查看，以及日报/周报/月报智能生成功能。

## 需求分析

### 使用场景
- **辅助决策**: 帮助决策者了解行业动态，发现商业机会，调整合作策略
- **信息监控**: 监控竞争对手、政策变化、市场趋势，及时响应
- **报告生成**: 自动汇总信息，生成汇报材料给上级或客户

### 关键特性
- **垂直领域**: 专注于特定行业（如半导体、汽车、低空经济等）
- **智能推荐**: AI根据用户角色、关注领域推荐生成定制化报告
- **独立页面**: 在导航菜单中新增"行情速递"入口，作为独立模块展示

## 数据模型

### NewsItem（新闻条目）
```typescript
interface NewsItem {
  id: string;
  title: string;
  type: 'policy' | 'market' | 'tender' | 'hotspot';
  department: string;        // 发布部门
  publishTime: string;      // 发布时间
  tags: string[];           // 标签
  summary: string;          // 摘要
  content?: string;         // 完整内容（详情页使用）
  isCollected?: boolean;    // 是否收藏
}

// 招标信息扩展
interface TenderItem extends NewsItem {
  deadline: string;         // 截止时间
  budget: string;          // 预算金额
  region: string;          // 地区
  requirements: string;    // 具体要求
}
```

### ReportConfig（报告配置）
```typescript
interface ReportConfig {
  type: 'daily' | 'weekly' | 'monthly';
  startDate: string;
  endDate: string;
  includePolicy: boolean;
  includeMarket: boolean;
  includeTender: boolean;
  includeHotspot: boolean;
  focusArea: string;       // 关注领域
}
```

### UserPreference（用户偏好）
```typescript
interface UserPreference {
  focusIndustries: string[];    // 关注行业
  focusRegions: string[];       // 关注地区
  collectedItems: string[];     // 收藏的内容
}
```

## 核心组件

### NewsFeedModule（行情速递主模块）
- 负责整体布局和状态管理
- 管理筛选器、搜索、分类切换
- 协调各个子组件

### CategoryNav（分类导航）
- 显示分类列表（全部/政策/市场/招标/热点/收藏）
- 显示每个分类的新增数量
- 处理分类切换

### NewsCard（信息卡片）
- 根据 type 显示不同样式
- 显示标题、时间、摘要、标签
- 提供收藏、分享等操作

### ReportGenerator（报告生成器）
- 报告配置表单
- 智能推荐内容展示
- 报告预览和生成

### FilterBar（筛选栏）
- 时间范围选择（今日/本周/本月）
- 分类筛选
- 搜索功能

2. 实现报告预览

### 第四阶段：优化完善
1. 添加动画效果
2. 响应式适配
3. 性能优化
4. 错误处理

## 注意事项

1. **数据模拟**: 使用真实的业务场景数据，确保数据格式合理
2. **交互体验**: 卡片点击、收藏、筛选等操作要有即时反馈
3. **响应式设计**: 支持桌面端和移动端适配
4. **性能优化**: 大量数据时使用虚拟滚动或分页
5. **扩展性**: 预留接口，便于后续接入真实后端API
