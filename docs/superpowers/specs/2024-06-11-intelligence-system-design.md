# 中国赛宝实验室情报速递系统设计文档

**创建日期**: 2024-06-11  
**设计者**: Claude  
**状态**: 已批准

## 项目概述

为赛宝实验室设计情报速递系统，提供自动采集、智能整理、精准推送、归档查询的行业情报工具，覆盖政策、标准、技术、招标、竞品五大核心场景，轻量化、适配研究所日常办公使用。

## 实施策略

**方案选择**: 方案 A - 渐进式扩展
- 在现有 NewsFeedModule 基础上扩展
- 创建新的 IntelligenceModule 组件
- 复用现有 UI 组件和样式
- 保持与现有系统的一致性

## 数据模型

### IntelligenceItem（情报条目）

```typescript
interface IntelligenceItem {
  id: string;
  title: string;
  type: 'policy' | 'standard' | 'technology' | 'tender' | 'competitor';
  
  // 基础信息
  department: string;
  publishTime: string;
  tags: string[];
  summary: string;
  content?: string;
  
  // 价值标注
  priority: 'urgent' | 'important' | 'normal';  // 紧急/重点/普通
  isHighlighted: boolean;  // 是否标红置顶
  
  // 业务匹配
  businessMatch: string[];  // 匹配的业务线
  relevanceScore?: number;  // 相关度评分
  
  // 推送状态
  pushStatus: 'pending' | 'pushed' | 'read';
  readCount?: number;
  
  // 来源
  source: string;
  sourceUrl?: string;
}

// 标准条目扩展
interface StandardItem extends IntelligenceItem {
  standardNumber: string;
  effectiveDate?: string;
  replaceStandard?: string;
  status: 'draft' | 'effective' | 'revised' | 'deprecated';
}

// 招标条目扩展
interface TenderItem extends IntelligenceItem {
  budget: string;
  deadline: string;
  region: string;
  requirements: string;
  contactInfo?: string;
}
```

### IntelligenceReport（情报简报）

```typescript
interface IntelligenceReport {
  id: string;
  type: 'daily' | 'weekly' | 'monthly';
  title: string;
  generatedAt: string;
  dateRange: string;
  
  // 包含内容
  includePolicy: boolean;
  includeStandard: boolean;
  includeTechnology: boolean;
  includeTender: boolean;
  includeCompetitor: boolean;
  
  // 选中的情报条目
  selectedItemIds: string[];
  
  // 生成状态
  status: 'draft' | 'generating' | 'completed';
  downloadUrl?: string;
}
```

## 核心组件设计

### IntelligenceCard（情报卡片）

根据 5 种情报类型显示不同样式：
- **政策法规**: 蓝色主题，显示政策文号
- **标准更新**: 紫色主题，显示标准号、生效日期
- **产业技术**: 绿色主题，显示技术关键词
- **招标项目**: 橙色主题，显示预算、截止时间
- **竞品动态**: 红色主题，显示竞品名称

特殊标注：
- 🔴 紧急/重要情报：红色边框 + 置顶显示
- 💡 业务匹配：显示匹配的业务线标签
- 📊 推送状态：显示推送和阅读状态

### IntelligenceGenerator（简报生成器）

- 报告类型选择（每日/每周/每月）
- 情报类型筛选（5种类型可多选）
- 价值筛选（紧急/重要/普通）
- 业务匹配筛选
- 智能推荐：根据业务线推荐相关情报
- PDF生成预览
- 一键下载

### IntelligenceFilter（高级筛选）

- 时间范围选择
- 情报类型筛选
- 业务线筛选
- 关键词搜索
- 推送状态筛选

## 注意事项

1. **数据模拟**: 使用真实的业务场景数据，确保数据格式合理
2. **交互体验**: 卡片点击、收藏、推送等操作要有即时反馈
3. **响应式设计**: 支持桌面端和移动端适配
4. **性能优化**: 大量数据时使用虚拟滚动或分页
5. **扩展性**: 预留接口，便于后续接入真实后端 API
