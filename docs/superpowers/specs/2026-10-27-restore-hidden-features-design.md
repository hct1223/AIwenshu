# 恢复全部隐藏功能与菜单设计

## 目标

恢复项目中此前隐藏的全部功能入口与菜单，使现有路由和组件重新可访问，同时保留当前页面逻辑，不进行无关重构。

## 恢复范围

- 侧边栏恢复“企业管理”“企业搜索”“情报速递”“知识库管理”四个菜单。
- 首页恢复“大盘分析”按钮及其结果面板。
- 保留“数据大盘研判”和“数据指标配置”两个现有菜单。
- 保留现有路由、组件、分析状态和处理函数。

## 实现方式

- 在 `src/App.tsx` 的 `navMenuItems` 中按原业务顺序恢复四个菜单项，使用现有图标和英文描述。
- 在 `src/components/DashboardModule.tsx` 中将 `DASHBOARD_ANALYSIS_ENABLED` 设置为 `true`，同时恢复按钮和结果面板的显示。
- 不新增全局功能开关，不修改页面内部业务逻辑。

## 验收标准

- 侧边栏同时显示六个业务菜单。
- 四个恢复的菜单均可切换到对应页面。
- 首页“大盘分析”按钮可见，点击后能显示加载态并渲染分析结果。
- 本次改动不引入新的 TypeScript 编译错误。
